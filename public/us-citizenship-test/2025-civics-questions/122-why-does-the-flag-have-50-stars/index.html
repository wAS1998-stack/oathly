Why does the flag have 50 stars?

2025 civics test · question 122 of 128Symbols and Holidays: Symbols

Answer (any one of these)

  • (Because there is) one star for each state
  • (Because) each star represents a state
  • (Because there are) 50 states

You only need to give one of these answers. Pick the one that is easiest for you to remember and say.

Why this is the answer

Each of the 50 stars stands for one state. The 50-star flag has been used since 1960, after Hawaii became the 50th state in 1959.
